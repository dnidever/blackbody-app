# Blackbody Explorer

An interactive Streamlit app for plotting and comparing blackbody spectra in an astronomy class.

## Run it

```bash
python -m pip install -r requirements.txt
streamlit run app.py
```

The plot toolbar saves a PNG with its camera button. The buttons below the plot download an interactive HTML figure and a text file containing wavelengths, all plotted curves, peak locations, displayed-range integrals, and bolometric fluxes.
